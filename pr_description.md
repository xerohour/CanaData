💡 What
Added a skip-to-content link (`.skip-link`) and `:focus-visible` styles to the HTML generated by `parse-script/CanaParse.py`. Also added `id="main-content"` and `tabindex="-1"` to the main container wrapper so that it can receive focus when the skip link is triggered.

🎯 Why
This ensures the dynamically generated HTML report from `parse-script/CanaParse.py` provides the exact same keyboard accessibility improvements that were recently added to `generate_report.py`, providing a consistent accessible experience for keyboard users trying to bypass long lists of items.

📸 Before/After
N/A - invisible unless navigated via keyboard (Tab key).

♿ Accessibility
- Allows screen reader and keyboard-only users to skip navigation elements and jump straight to the main content table.
- Added explicit visual focus indicators via `*:focus-visible` to assist sighted users relying on keyboard navigation.
- Maintained proper focus management by ensuring the target destination sets `tabindex="-1"`.

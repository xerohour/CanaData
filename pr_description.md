💡 What:
Added accessibility improvements to the dynamic HTML report tables generated by CanaParse.py.
- Added `aria-label` attributes to the pagination Previous/Next buttons.
- Added `aria-live="polite"` to the pagination info text (e.g., "Showing 1-10 of 100") so screen readers automatically announce page changes.
- Added dynamic `aria-sort` attributes to table headers (`th`) that update to `ascending` or `descending` when the table is sorted via JavaScript.

🎯 Why:
The generated HTML reports rely heavily on JavaScript for pagination and sorting. Without proper ARIA attributes, screen reader users miss crucial context about table state (sort direction) and dynamic content updates (changing pages). This small change makes the robust data tables fully accessible to assistive technologies.

📸 Before/After:
*Before:* `<button class="btn">Previous</button>` and `<th aria-label="Sort by Price">Price</th>`
*After:* `<button class="btn" aria-label="Previous page">Previous</button>` and `<th aria-label="Sort by Price" aria-sort="ascending">Price</th>`

♿ Accessibility:
- Improves WCAG 2.1 Level A compliance for dynamic content updates (`aria-live`).
- Enhances table navigation for screen reader users by properly communicating sort state (`aria-sort`).
- Provides explicit context for icon-only or generic pagination buttons (`aria-label`).

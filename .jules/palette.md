## 2025-01-01 - Enhance dynamic component accessibility
**Learning:** Adding dynamic pagination status using innerHTML without `aria-live` means screen readers won't announce the change. Simply using `disabled` attribute on an element visually styles it in the browser, but it's important to provide complete semantic and visual clues (`cursor: not-allowed` + `aria-disabled="true"`) to all users. Additionally, purely decorative emojis must be explicitly hidden.
**Action:** When creating dynamic status elements or dynamically modifying DOM buttons in jQuery/JS, ensure `aria-live="polite"` is added for non-disruptive announcements, and interactive disabled components receive `cursor: not-allowed` along with `aria-disabled="true"`. Wrap decorative emojis in `<span aria-hidden="true">`.

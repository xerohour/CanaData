## 2026-02-24 - Path Traversal in CSV Export
**Vulnerability:** User-controlled filenames in `csv_maker` allowed writing files outside the intended directory via `../` sequences.
**Learning:** Even internal utility functions like `csv_maker` can be vulnerable if they accept unsanitized input derived from user arguments (`searchSlug`).
**Prevention:** Always sanitize filenames using allowlists (alphanumeric, etc.) before using them in file operations, especially when they originate from user input.

## 2024-06-28 - XSS in Optional API Fields during HTML Generation
**Vulnerability:** Unsanitized nested API fields (like `promo_code` or `avatar_image`) were directly embedded into the static HTML generated by `generate_report.py` using f-strings, enabling Cross-Site Scripting (XSS).
**Learning:** In architectures generating static HTML via Python f-strings, even seemingly innocuous optional or deeply nested fields from external sources must be treated as untrusted input.
**Prevention:** Always wrap dynamically interpolated external data using `html.escape(str(...))` before including it in an HTML string context.
